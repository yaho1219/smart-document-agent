# 샘플 이미지 폴더

데모 및 LayoutLM 파인튜닝에 사용할 이미지를 이 폴더에 넣으세요.

- `labels.csv`의 `filename` 컬럼과 실제 파일명을 맞추세요.
- 권장: 영수증 2~3장, 명함 2~3장.
- 지원 포맷: jpg, jpeg, png, bmp, webp.

예시 파일명(현재 `labels.csv` 기준):
- `receipt_01.jpg`, `receipt_02.jpg`
- `card_01.jpg`, `card_02.jpg`

> 실제 이미지는 저장소에 포함하지 않습니다. 발표 전 본인 이미지를 추가하세요.
